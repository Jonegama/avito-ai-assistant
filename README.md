# AI-ассистент для улучшения объявлений на Авито
Тестовое задание для стажёра Frontend (весенняя волна 2026)

## О проекте
Веб-приложение представляет собой личный кабинет продавца с AI-ассистентом, который помогает улучшать объявления.

Функциональность:
- просмотр списка объявлений
- просмотр карточки объявления
- редактирование объявления
- генерация описания через AI
- оценка рыночной цены через AI
- сохранение изменений
- хранение черновика в localStorage

## Реализованные страницы
/ads
- список объявлений
- поиск
- сортировка
- фильтры
- пагинация
- переключение сетка/список

/ads/:id
- просмотр объявления
- характеристики
- описание
- блок "Требуются доработки"
- переход к редактированию

/ads/:id/edit
- редактирование объявления
- генерация описания
- получение цены от AI
- сохранение изменений
- черновик в localStorage

## Стек
- React
- TypeScript
- Vite
- react-router-dom
- Fetch API
- Ollama (LLM)
- Node.js (proxy server)

## Установка
### Frontend
npm install  
npm run dev 

http://localhost:5173

### Backend объявлений
cd server  
npm install  
npm start  

http://localhost:8080

### AI proxy
node server.js  

http://localhost:3000

## Ollama
Установить Ollama
Скачать модель:
ollama pull llama3  
Запустить:
ollama serve  

## Переменные окружения
Создать .env файл:

VITE_API_URL=http://localhost:8080  
VITE_AI_API_URL=http://localhost:3000  

## Черновики
Данные формы сохраняются в localStorage
Ключ:
ad-edit-draft-{id}
